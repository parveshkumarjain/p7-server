HOW THIS WORKS
1Your iPhone tool calls a free cloud server you deploy once
2The server fetches NSE data (yfinance) and sends it to your phone
3Works on iPhone anywhere — no laptop, no API subscription needed
DEPLOY THE SERVER (5 MIN, FREE)
1Create free account at github.com if you don't have one
2Create new repo, upload p7_server.py and requirements.txt
3Go to render.com → free account → New Web Service → connect your GitHub repo
4Set: Language = Python, Start Command = gunicorn p7_server:app
5Deploy. Copy the URL (e.g. https://p7-xxx.onrender.com)
6Paste URL below and tap Connect
YOUR RENDER SERVER URL
After saving: Safari → Share button → "Add to Home Screen" to install as iPhone app.

Note: Free Render tier sleeps after 15 min inactivity. First scan may take ~30 seconds to wake up — subsequent calls are instant.
